# CRM Backend

CRM Backend is a Laravel-based REST API designed for a WhatsApp Business CRM platform.

## Features
- Customer management
- WhatsApp Business integration
- Conversation and chat handling
- Contact and lead management
- Campaign management
- Authentication & authorization
- RESTful API architecture
- Webhooks support
- Notifications and automation
- Reporting and analytics

## Tech Stack
- Laravel
- MySQL
- REST API
- Queue Jobs
- Webhooks
- JWT / Sanctum Authentication

## Purpose
This backend powers the CRM system and provides APIs for managing WhatsApp business communication and customer interactions efficiently.
